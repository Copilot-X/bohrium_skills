# Bohrium Product Arena — Period 4 Skills

This repository contains the Period 4 submissions for the Bohrium
Product Arena weekly competition.  Each directory under `skills/` is a
self-contained Skill package: `SKILL.md`, `task.json`, `scripts/`,
`templates/`, `references/` and synthetic `examples/`.

The examples are synthetic interface samples, not formal case answers.
They exist to show the input/output shape and are labelled as such.

## Runtime

The evaluator installs one Skill under `/skills/weekly-skill` and runs
the official harness.  The entry point is:

```bash
python3 "$SKILL_DIR/scripts/run_case.py" prepare --input /input --work /app/work --output /app/output
# model writes the work file described in SKILL.md
python3 "$SKILL_DIR/scripts/run_case.py" finalize --input /input --work /app/work --output /app/output
```

Every run writes an honest `result.json`; partial and input_error
states are explicit and never replaced by fabricated content.
