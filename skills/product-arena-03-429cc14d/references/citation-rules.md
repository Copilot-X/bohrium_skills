# 引用管理规则

## 1. 引用位置

- 引用必须落在支撑该论断的句子内；优先 `after_anchor`。
- 一句多引：同一位置给多个 `ref_keys`。
- 多句一引：每句单独一条 insertion；不要在一个段尾堆引用。
- 图表注、方法步骤、结论句分别判断；不把方法引用挂到结果句。

## 2. 编号

- 顺序编码制（GB/T 7714、IEEE、Vancouver）：按正文首次出现分配 1..N。
- 作者—年份制（APA）：不编号，按作者姓氏与年份排序。
- 插入/删除/调序后，正文标记与文末列表必须同步。
- 现有引用编号保留其条目；新引用顺延并重排，不能出现重复编号。

## 3. 去重

优先判据：

1. DOI 完全相同（忽略 `https://doi.org/` 前缀）；
2. 规范化标题 + 年份 + 第一作者姓氏相同；
3. 预印本与正式版：DOI 相同或标题/作者/年份一致，保留正式版；
4. 不同数据库导出：字段差异不构成不同文献。

禁止：

- 仅因标题相似就合并不同文献；
- 把同名作者的不同论文合并；
- 把不同年份/不同卷期的同题文章合并。

每条合并必须写 `basis`；无法确定时 `keep_separate`。

## 4. 格式

- GB/T 7714—2015：作者. 题名[J]. 刊名, 年, 卷(期): 页. DOI.
- APA 7：Author, A. A. (Year). Title. Journal, Vol(Issue), pages. https://doi.org/...
- IEEE：A. Author, "Title," Journal, vol. X, no. Y, pp. Z, Year.
- Vancouver：Author. Title. Journal. Year;Vol(Issue):Pages.

字段缺失时保留已有信息，不编造卷期页；在 `uncertainty` 标注。

## 5. 核验

- 每个 `ref_key` 必须存在；不存在写入 `unresolved`，不插入。
- `metadata_fixes` 必须有来源；无来源不改。
- 正文引用 token 与文末编号逐一对应。
- 条目重复、编号冲突、孤儿条目都要报告。

## 6. 失败模式

| 失败 | 后果 | 处置 |
|---|---|---|
| 引用挂错句 | 证据不支撑 | 回到 citation-points 重选句子 |
| 编号不同步 | 读者无法定位 | 重排并重建列表 |
| 误合并 | 文献丢失 | `keep_separate` + `basis` |
| 编造元数据 | 学术不端风险 | 只保留输入字段 |
| 预印本重复 | 列表冗余 | DOI/标题判据合并 |
