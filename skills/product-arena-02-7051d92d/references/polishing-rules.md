# 学术语言润色规则

## 1. 最小编辑

- 先判断错误类型：语法/句法、搭配、术语、语域、连贯、标点。
- 能改词就不改句；能改句就不重写整段。
- 不做无理由的同义替换；不把作者的具体表述改成空泛概括。
- 每条编辑必须有 `before`（逐字来自原文）、`after`、`type`、`reason`。

## 2. 语义保持

| 维度 | 必须保持 | 常见错误 |
|---|---|---|
| 限定强度 | `may < suggest < indicate < show < prove` | 把 `may` 改成 `is` |
| 因果/相关 | `associated with` 不改成 `causes` | 把相关性写成因果 |
| 否定范围 | `not all` 不改成 `none` | 否定词位置移动 |
| 条件 | `if/under ... conditions` 不删 | 为顺句删掉条件 |
| 量词 | `some/most/all` 不升级 | `some` 改成 `all` |
| 数字/单位 | 值、有效数字、单位、样本量不变 | 顺手四舍五入/换算 |
| 引用/图表 | 编号与指向不变 | 移动句子后引用错位 |

## 3. 术语与语域

- 同一概念全文一种写法；缩写首次出现给出全称；大小写/连字符统一。
- 期刊论文：避免口语化、宣传化、绝对化；少用第一人称堆叠。
- 学位论文：可展开背景，但不改变事实与限定。
- 基金申请：强调意义与创新，但不夸大适用范围。
- 审稿回复：礼貌、逐条对应，不回避审稿人问题。

## 4. 修改类型标签

- `grammar`：主谓一致、时态、冠词、介词、单复数、悬垂修饰。
- `term`：术语、缩写、大小写、连字符、同义混用。
- `register`：口语化、宣传化、绝对化、人称误用。
- `clarity`：长句切分、指代明确、信息重心调整。
- `cohesion`：连接词、段落承接、重复冗余。
- `typography`：标点、空格、单位格式、英文/中文标点。

## 5. 失败模式

| 失败 | 后果 | 处置 |
|---|---|---|
| 整段重写 | 作者主张被改变 | 退回最小编辑 |
| 情态升级 | 结论越界 | 恢复 `may/suggest` |
| 数字被改 | 事实错误 | 恢复原值并在报告中记录 |
| 引用错位 | 证据链断裂 | 保持引用在原句/原位置 |
| 术语漂移 | 全文不一致 | 用 glossary 回填 |
| 只给建议不给改文 | 不可交付 | 必须给 before/after |
